# 内控计划系统 - 内网部署指南

## 快速开始（3步搞定）

### 第1步：开放防火墙端口
右键点击 `开放防火墙端口.bat` → **以管理员身份运行**
- 自动开放 3000 端口
- 脚本会显示你的内网 IP 地址，记下来

### 第2步：启动服务
双击 `启动服务.bat`
- 自动检查并安装 Node.js 依赖
- 自动安装 pm2 进程管理器
- 后台启动服务，崩溃自动重启
- 提示是否设置开机自启（建议选 Y）

### 第3步：分享给同事
```
访问地址: http://你的IP:3000
测试账号: 000000 / admin123
```

---

## 常用操作

### 查看服务状态
打开 cmd 执行：
```cmd
pm2 status          # 查看运行状态
pm2 logs icp-system # 查看实时日志
pm2 restart icp-system # 重启服务
```

### 停止服务
双击 `停止服务.bat`

### 数据备份
- 双击 `数据备份.bat` 手动备份
- 数据库文件位置：`data/icp.db`
- 建议设置 Windows 任务计划，每天凌晨自动备份

---

## 部署架构说明

```
用户浏览器 ←→ Node.js 服务 (:3000) ←→ SQLite 数据库 (data/icp.db)
```

- 前端页面由 Node.js 直接托管（public 目录）
- 数据库是单文件 SQLite，无需额外安装数据库
- pm2 负责进程管理，保证服务稳定运行

## 常见问题

### Q: 同事访问不了？
1. 确认防火墙端口已开放
2. 确认在同一局域网内
3. 关闭电脑上的 360/金山毒霸 等安全软件试试

### Q: 服务挂了怎么办？
pm2 会自动重启。如果频繁崩溃，用 `pm2 logs icp-system` 看日志排查。

### Q: 想改端口？
编辑 `ecosystem.config.js`，把 `PORT: 3000` 改成你要的端口，然后 `pm2 restart icp-system`。

### Q: 数据存在哪？安全吗？
- 所有数据都在 `data/icp.db` 一个文件里
- 定期备份这个文件就不会丢数据
- 建议备份到另一台机器或网盘

### Q: Win7 电脑访问空白？
使用 Win7 兼容版部署，或让用户用 Chrome/Edge 浏览器访问。
