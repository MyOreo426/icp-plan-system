内控计划系统 - Win7 绿色源码版
============================

系统要求：
- Windows 7 及以上
- 需要安装 Node.js 12.x（推荐 12.22.12）

启动方式：
1. 安装 Node.js 12.x
2. 在此目录下打开命令行，运行：npm install
3. 启动服务：node server.js
4. 打开浏览器访问 http://localhost:3000
5. 默认账号：admin / admin123

注意：
- 本版本需要 Node.js 环境
- 如需单文件版，请使用 exe 版本
- 数据保存在 data/ 文件夹中
