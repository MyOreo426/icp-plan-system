内控计划系统 - Win7 兼容版
============================

【快速启动】
1. 安装 Node.js (v12 或更高版本)
2. 打开 cmd，进入当前目录
3. 执行: npm install
4. 执行: node server.js
5. 浏览器访问: http://localhost:3000

【推荐方式】
双击 "启动服务.bat" 自动安装并后台运行

【默认账号】
管理员: 000000 / admin123
主任: ZR / director123
组长: MY / leader123 (综合组)
组长: DH / leader123 (客户组)
组员: ZZY / member123 (综合组)
组员: A1 / member123 (客户组)

【Win7 兼容说明】
- 已替换所有 ?. 可选链语法
- 推荐使用 Chrome 或 360极速浏览器
- IE 浏览器不支持
